# Round 1: The Plan (summary)

The full, sourced plan (problem evidence, users, research plan, solution, workflow diagram, features, stack, responsible design, development plan, impact and sources) is in the Claude document "BrandSentinel – Round 1 Plan". Export it from that document as Word, PDF or Markdown and submit it. This file is a pointer so the repository stays self-contained.

**One-paragraph summary.** Organisations publish through many people, agencies and AI tools, and brand guidelines are rarely enforced: 81% of companies deal with off-brand content and only about 30% consistently enforce guidelines (vendor-published Marq/Lucidpress figures); 36.5% of surveyed marketers say AI errors have already gone public (NP Digital); 94.8% of home pages fail at least one automatically detectable WCAG test (WebAIM 2025). BrandSentinel checks content against approved sources before publication, explains each finding with its source, suggests corrections that preserve intent, and keeps humans in charge through a role-based review, approval and audit workflow, with insights into repeated mistakes and unclear guidelines.

Status of the plan's items in this build: delivered in the MVP (guideline and fact import via versioned kit; text, Markdown, HTML, docx and image review; tone, terminology, claims, visual and accessibility checks; explanations with sources; non-automatic suggestions; comments, approvals, revision history, roles; insights; confidentiality controls and AI disclosure). Not delivered: pixel-level image analysis, PDF input, Google Docs and Word add-ins, SSO. The original plan used React, FastAPI and Postgres; the MVP uses a dependency-free Python server, vanilla JS and SQLite so it runs anywhere, and the roadmap covers the move to a production stack.
