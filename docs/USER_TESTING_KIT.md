# User testing kit (no results are included here: run the sessions and record real data)

**Participants:** 5 to 8 people across the roles: 3 content creators, 2 brand or marketing managers, 1 to 2 compliance or review staff. 30 minutes each, consent to record notes, no real confidential content.

## Tasks
1. As a creator, paste a real draft (or the sample launch email) and read the findings. Say aloud what each finding means.
2. Fix three findings: accept one automatic suggestion, edit one manually, dismiss one with a reason.
3. Submit for review.
4. As a reviewer, request changes, then approve a corrected version.
5. As a manager, find which guideline causes the most dismissals.

## Measure
Task success (yes/partial/no), time per task, errors, and rate each 1 to 5 afterwards: "I understood why each finding was raised", "I trusted the suggestions", "I felt in control of the final decision", "this would reduce my review effort". Record every suggestion accepted or rejected and why, and every false alarm.
